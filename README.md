# 📚 勉強進捗トラッカー

毎日の勉強を「科目」と「時間（分）」で記録し、**今日の合計**と**これまでの累計**がひと目で分かる、自分専用の勉強記録ツールです。
ビルド不要・サーバー不要・外部依存ゼロ。`index.html` をブラウザで開くだけで動きます。

## 主な機能（v1）

- ✏️ **記録の追加** — 科目・時間（分）・日付を入力して保存
- ⏱️ **合計表示** — 「今日の合計」を大きく、その下に「累計合計」を `◯時間◯分` で表示
- 📋 **一覧と削除** — 記録を新しい順で一覧表示。削除は確認ダイアログ付き
- 💾 **自動保存** — ブラウザの localStorage に保存（リロードしても消えません）
- 📱 **レスポンシブ** — iPad / iPhone の Safari を主対象に、PC でも崩れません

## 使い方

1. `index.html` をブラウザで開きます。
2. 「科目」「時間（分）」を入力（日付は既定で今日）。
3. 「記録する」を押すと保存され、合計と一覧がすぐに更新されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | HTML / CSS / JavaScript をすべてインラインで含む単一ファイル |

外部ファイル・CDN・フレームワークは一切使っていません。

## データについて

記録はお使いのブラウザ内（localStorage、キー名 `studyTracker.records.v1`）にのみ保存されます。
サーバーには送信されないため、別の端末やブラウザとは共有されません。

## 公開（GitHub Pages）

`index.html` がリポジトリのルートにあるため、`Settings → Pages → Deploy from a branch（main / root）` でそのまま公開できます。
