# 📋 タスク管理アプリ

勉強や仕事の進捗を簡単に管理できる、シンプルなタスク管理アプリです。
ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで動きます。

## 主な機能

- ✅ **タスクの追加・完了・削除** — ワンクリックで進捗を更新
- 🏷️ **カテゴリ分け** — 勉強 / 仕事 / その他で整理
- 🔴 **優先度設定** — 高・中・低の3段階（優先度順に自動ソート）
- 📅 **期限管理** — 期限切れ・期限間近を色付きで強調表示
- 🔍 **フィルター** — 状態（未完了/完了）やカテゴリで絞り込み
- 📊 **進捗サマリー** — 全タスク数・完了数・達成率を一目で確認
- 💾 **自動保存** — ブラウザの localStorage にデータを保存（再読み込みしても消えません）
- 📱 **レスポンシブ対応** — スマホでも快適に利用可能

## 使い方

1. このリポジトリをクローン、またはファイルをダウンロードします。
2. `index.html` をブラウザで開きます。
3. フォームにタスクを入力して「追加」を押すだけ。

```bash
git clone <このリポジトリのURL>
cd 2026-06-06test
# index.html をダブルクリック、またはブラウザにドラッグ
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造（HTML） |
| `styles.css` | デザイン・レイアウト（CSS） |
| `app.js` | ロジック・データ保存（JavaScript） |

## 技術

- 純粋な HTML / CSS / JavaScript（フレームワーク・依存パッケージなし）
- データ保存に Web Storage API（localStorage）を使用

## データについて

タスクはお使いのブラウザ内（localStorage）にのみ保存されます。
サーバーには送信されないため、別の端末やブラウザとは共有されません。
