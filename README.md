# 📚 学習時間トラッカー

日々の学習時間を「科目」と「時間（分）」で記録し、**今日の達成率**と**週間／月間の積み上げグラフ**で継続を可視化する、シングルページの学習記録ツールです。
ビルド不要・サーバー不要。`index.html` をブラウザで開くだけで動きます（外部依存は Chart.js の CDN のみ）。

## 主な機能

- ✏️ **記録入力** — 科目名（プルダウン候補 or 手入力）と学習時間（分）を入力して保存
- 🎯 **今日の達成率** — 設定した「1日の目標時間」に対する合計時間・プログレスバー・％を表示（達成時はグリーンで強調）
- 📊 **積み上げ棒グラフ** — 週間（7日）／月間（30日）タブを切り替え、科目ごとに色分けして表示。目標ラインを破線で重ねます
- 📋 **記録履歴** — 新しい順に最大50件表示。各行から削除（確認ダイアログ付き）
- ⚙️ **設定** — 目標時間の設定、科目の色変更・削除（記録は保持）
- 💾 **データ管理** — 全記録の JSON エクスポート／全データ削除
- 📱 **レスポンシブ** — PC・iPad 横は2カラム、スマホ・iPad 縦は1カラム

## 使い方

1. `index.html` をブラウザで開きます。
2. 「科目名」「学習時間（分）」を入力し、「記録する」を押すと保存されます。
3. 設定エリアで「1日の目標時間」を入力すると、ヘッダーに達成率が表示されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | HTML / CSS / JavaScript をすべてインラインで含む単一ファイル |

外部依存は Chart.js（CDN）のみです。

## データについて

データはお使いのブラウザ内（localStorage）にのみ保存されます。サーバーには送信されません。

| キー | 内容 |
| --- | --- |
| `study_records` | 学習記録の全データ |
| `study_subjects` | 登録済み科目（名前・色） |
| `study_settings` | アプリ設定（1日の目標時間） |

容量上限（約5MB）に近づくと警告を表示します。バックアップには JSON エクスポートをご利用ください。

## 動作環境
